What to notice

        
    
          
  • The biggest value "bubbles" to the right in the very first pass.
    • 
          
  • Each pass compares one fewer pair — the green tail never changes again.
    • 
          
  • Try an already-sorted input: one pass with zero swaps, and it stops.

You might think…

        
…that it always needs n passes. With the early-exit check it stops as
          soon as a pass makes no swaps, so sorted input costs only O(n).
